    With custom support for additional CSS from W3C documents, many
    unachievable by today's browser can be implemented. As compared to

    for the rendering, thus it automatically supports the powerful
    already available CSS on browsers. In this document so far, these
    are used:

    - Placing elements outside into the page margin
    - Generating chapter names and links with page number
    - Blank page for aligning next page to the book left/right side.
